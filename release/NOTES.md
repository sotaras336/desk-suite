## Desk 3.8.4

**Maximized windows land full size on the other screen**

- DeskBar: moving a maximized window to a screen with a different scale (for example Win+Shift+Arrow from a 200% laptop screen to a 100% monitor) could leave some apps, like Minecraft, a little short of the bar with the bottom of their picture cut off. DeskBar now sets the right size the moment the window arrives, so it lands filling the screen.

**What you need:** Microsoft's free [.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0) for DeskDrawer and DeskTune; DeskBar needs nothing extra. With 2.2 or later installed, each app offers this update itself. The files aren't code-signed, so Windows SmartScreen asks the first time you run a downloaded setup: More info, then Run anyway. Checksums are in `SHA256SUMS.txt`.
