## Desk 4.0.1

A small update to Desk 4.0. Only DeskTune changed (DeskBar and DeskDrawer are the same files as 4.0).

- **DeskTune:** after "Unlock services", the window that runs as administrator only comes to the front when another DeskTune start asks. It no longer closes, or puts everything back, because a program without administrator rights asked it to. If you press "Put everything back" in Desk settings while that window is open, it comes to the front and you press Undo all yourself.
- The Desk website now shows the 4.0 features, the right file sizes, the all-in-one `Desk-Setup.exe` and the bug report form.

Everything else is as in [Desk 4.0](https://github.com/sotaras336/desk-suite/releases/tag/v4.0). Checksums are in `SHA256SUMS.txt`.
