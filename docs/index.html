Desk

A lighter Windows desktop.

Three small apps that replace the taskbar, File Explorer and the clutter you never asked for, and tune your screens. Free, no account, and no tracking.

Download the apps See what each one does

For Windows 10 and 11, 64-bit. Each app is under 2 MB.

DeskBar.

Replaces the taskbar, Start and Quick Settings

A taskbar that starts fast, stays out of your way and opens what you search for.

  • Start with your pinned apps, folders and recent files, and a search that finds any app, setting, file or folder on your PC as you type.
  • Quick Settings for Wi-Fi, Bluetooth, sound, brightness, night light and energy saver, plus connecting Bluetooth headphones in one tap.
  • Window previews, show desktop in the corner, and a clock with calendar.
  • Ten colour themes, including black, white and glass.
  • Native code, about 1.7 MB. Windows' own taskbar comes back the moment DeskBar quits.
Download DeskBar 1.9 MB

DeskDrawer.

Replaces File Explorer

A file manager with tabs that opens folders as fast as you click them.

  • Tabs you can drag, reopen and duplicate; a breadcrumb path bar you can click and type into; a drag-select box; Ctrl+Z even after Delete; search that streams in the best matches first and can look through the whole PC.
  • Optional: when Word, Chrome or any other app opens an Open or Save window, DeskDrawer's own picker can answer it instead, with the same file types as a drop-down. Off until you switch it on.
  • Details, list, tiles and icon views with real thumbnails, grouping by date or type, and folder sizes.
  • Your Quick access pins, a Home page with recent files, and This PC with how full each drive is.
  • Undo for rename, move, copy and new files. ZIP and unzip built in.
  • Optional: make folders and Win+E open here instead of File Explorer. Switch it off and everything is as before.
  • Stays ready in the background after you close it, like File Explorer, so folders open in about half a second. It uses about 20–30 MB of memory while it waits, and you can switch that off.
Download DeskDrawer 1.1 MB

DeskTune.

Switches off what you don't use

A debloater that tells you what each switch costs before you flip it, and can undo every change.

  • Startup apps, Widgets, Copilot, Edge and Chrome running after you close them, ads and suggestions, telemetry and unused services, preinstalled apps.
  • Live memory use next to each item, and a plain line on what you'd lose.
  • Tick what you want, then apply once. Safe and Recommended presets pick for you.
  • Every change is logged and can be undone, one at a time or all together. A restore point is made before system changes.
  • It won't touch Windows Update, Defender or system files, and has no "RAM cleaner".
Download DeskTune 0.5 MB

DeskMode.

Built into DeskBar: the button next to the keyboard language

One panel for refresh rate, power mode and brightness, and a docked setup that switches itself when you plug in.

  • Plug in an external monitor and the charger and DeskMode goes to your "max" settings by itself: each screen at the refresh rate you picked, the power mode you picked, Energy saver off. Unplug and it puts everything back.
  • Go max and Go easy buttons, a power mode switch, refresh rate per screen and brightness per screen (the monitor too, over DDC/CI), with a "both" slider that keeps the gap between them.
  • What Go max and Go easy set is chosen on a page of the panel; whether it switches by itself is in DeskBar's settings, on the DeskMode page. Ctrl+Alt+D opens it, Ctrl+Alt+M and Ctrl+Alt+B are Go max and Go easy.
  • For games: leaves screen modes alone while a full-screen game is up, and Ctrl+Alt+F makes the window in front borderless full screen so alt-tab never blanks the screen.
  • Works with any monitor and any laptop or desktop. Energy saver and a few power modes use Windows features that vary between PCs, so DeskMode hides whatever your PC doesn't have.

Install in a minute

  1. Download the setup file

    Pick any of them. They work alone or together; DeskBar shows a DeskTune memory tile when both are installed.

  2. Run it

    Windows may say "Windows protected your PC" because the apps aren't code-signed yet. Choose More info, then Run anyway.

  3. That's it

    It installs for your account only, without administrator rights, adds a Start menu entry and opens.

DeskBar 1.9 MB DeskDrawer 1.1 MB DeskTune 0.5 MB

DeskDrawer and DeskTune need Microsoft's free .NET 10 Desktop Runtime (x64). If it's missing, Windows offers to install it the first time you open them. DeskBar (with DeskMode inside it) needs nothing extra.

Straight answers

Does anything get sent anywhere?
Almost nothing. None of the apps have accounts, telemetry or ads, and none sends anything about you or your PC. The one thing each app does by itself is look, about once a day, at the list of files in the newest release on GitHub to see whether a newer version is out (GitHub sees an ordinary download request, like any visit to this page). A new version is only installed when you press Update now, and the daily look can be switched off in each app's settings. The only web pages the apps open are ones you click, like a Wi-Fi sign-in page.
What do they change on my PC?
DeskBar hides Windows' taskbar while it runs and brings it back when it quits. DeskDrawer only opens your folders if you turn that on; it starts hidden when you sign in so it's ready (⋯ menu, "Keep ready in the background" to switch off). DeskTune changes only what you tick, records each change in %LOCALAPPDATA%\DeskTune\changes.json, and can put it back.
How do I uninstall?
Start menu, then "Uninstall DeskBar", "Uninstall DeskDrawer" or "Uninstall DeskTune". If you installed the separate DeskMode app before it moved into DeskBar, "Uninstall DeskMode" removes it. DeskDrawer hands folders back to File Explorer first. DeskTune leaves your applied changes in place, so use "Undo all" in DeskTune before uninstalling if you want Windows exactly as it was.
Why does Windows warn me when I run them?
Code-signing certificates cost money each year and these apps are free. Check the download against the SHA-256 checksums published with each release if you want to be sure it's the real file.
Which Windows versions?
Windows 10 and 11, 64-bit. DeskBar is developed and tested mostly on Windows 11 with a touchscreen and two monitors.
