## Desk 2.3.2

A DeskDrawer change. DeskBar, DeskTune and DeskMode are the same as in 2.3.1.

**DeskDrawer: the suggestions list under the path bar is gone.** 2.3 added a list of recent and matching folders under the address box; it was more in the way than useful, so it is removed (and the list of recent folders it used with it). Everything else about the path bar stays: a click on it anywhere except a folder name or its arrow turns it into a text box, Ctrl+L, F4 and Alt+D do the same, Enter goes to the typed folder, Esc cancels, and what you are typing is no longer wiped when the folder changes.

**What you need:** Microsoft's free [.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0) for DeskDrawer, DeskTune and DeskMode; DeskBar needs nothing extra. With 2.2 or later installed, DeskDrawer offers this itself: ⋯ menu, *Update DeskDrawer now*, or the link in its status bar. The files aren't code-signed, so Windows SmartScreen asks the first time you run a downloaded setup: More info, then Run anyway. Checksums are in `SHA256SUMS.txt`.
