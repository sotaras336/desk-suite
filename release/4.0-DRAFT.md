## Release notes: Desk 4.0

Desk 4.0 is the finished version of Pre-release 4: one settings window for the whole suite, a colour for each app, and a long list of fixes found while testing it. Each app offers it as its next update.

**One settings window, one look**

- One Desk settings window for DeskBar, DeskMode, DeskDrawer and DeskTune, opened from any of their gear buttons, on the right page.
- One colour for every app, or a different one for each. The full colour picker is in every app.
- New colour controls: Saturation, Softness and Fade.
- The lighter glass theme is in every app, DeskTune and DeskMode included.
- Desk apps installs, updates and opens DeskDrawer and DeskTune, each download checked against the release checksums.

**DeskBar**

- A tap just above the bar next to a maximized app no longer starts a resize of that app.
- The bar no longer freezes when an open app stops responding.
- App icons swell more smoothly when you point at them (Settings > Taskbar > Effects).
- Uses less memory.

**DeskDrawer**

- Press Space on a file for a big look at it without opening it. It now opens on the screen DeskDrawer is on, and closing it no longer crashes.
- Save As and Open pickers start in the folder the dialog is showing.
- Double-click in the Open picker opens the file.
- Clicking the selected sidebar folder again goes back to it.

**DeskTune**

- Follows colour changes made in DeskBar straight away.

**What you need:** Microsoft's free [.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0) for DeskDrawer and DeskTune; DeskBar needs nothing extra. The files aren't code-signed, so Windows SmartScreen asks the first time you run a downloaded setup: More info, then Run anyway. Checksums are in `SHA256SUMS.txt`.
